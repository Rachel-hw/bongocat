# 后台模式验证工具

独立于正式应用的最小实验，用于判断某个原生 macOS Bongo Cat 版本是否支持 F20，以及后续 Session 拦截是否能隔离前台输入。

```sh
bash scripts/build-background-probe.sh
```

输出到 `build/background-probe/`：

- `Bongo Tap Lab.app`：前台 F20 和后台 F20 两个测试，每轮固定 100 次。
- `Bongo Input Check.app`：独立输入窗口，统计到达它的 F20，不保存输入内容。
- `results/`：本地 JSON 结果；不提交至仓库。

在辅助功能设置中授权 Lab。每轮有 8 秒倒计时，按住 20ms，间隔随机 50–150ms。
前台测试让 Lab 接收 F20；后台测试由 Session 事件过滤器消费本轮标记的 F20。
两者均在 HID 层发送事件。每一对按下／松开必须确认，才允许下一对；确认超时停止。

后台测试时切换到 Bongo Input Check，验证普通打字、修饰键和编辑快捷键是否正常，
同时观察 F20 接收数是否保持为零。游戏计数需要单独读数；测试准确增量时不要操作键鼠，
否则真实输入也可能计入游戏。

## 本机验证记录

2026-10-16，Apple silicon、原生 macOS 版 Bongo Cat（当时 Steam build ID `25902419`）：

- 两轮 Lab 报告分别记录发送／释放 100，接收或拦截按下／松开 100。
- 用户确认前台、后台均通过，未感到正常输入异常。
- 独立输入窗口报告 F20 为 0／0；该报告只在启动、清零或收到 F20 时更新，时间戳不能单独证明整个测试期间的前台状态。

`transportPassed` 只代表工具内部收发一致。`gameCounterVerified` 保持 false，
因为应用没有读取游戏计数；用户反馈不改写成程序自动验证的结果。
这些结果限定于本机、当时游戏版本和实际测试过的输入场景，不代表所有应用和键盘工具组合。
